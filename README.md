Design Requirements:

* High Availability & Performance: FHRP(HSRP), LACP, Dual-Homed Edge, Rapid STP, VLANs,  2-Tier LAN Architecture.

* Routing Architecture: OSPF, external BGP.

* Security Policies: Port Security, DHCP Snooping, DAI, BPDU Guard, PortFast, Disabling unused ports, ACLs(Extended), Disabling CDP & LLDP,
Changing all L3 unused/end-points interfaces mode to passive (OSPF).

* Automation: Saving Device configurations in a yaml file, Daily backup for configurations, Scheduled checks, Event notifications

* Services: DHCP Server, DNS Server, Web Server.
